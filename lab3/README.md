# SportClub Lab 3 - React Project

Цей проект є лабораторною роботою №3 з використанням фреймворку React для онлайн-магазину SportClub.

## Вимоги

- Node.js (версія 18+ рекомендована)
- npm (постачається разом з Node.js)

## Встановлення та запуск

1. **Встановіть залежності:**
   ```
   npm install
   ```

2. **Запустіть сервер розробки:**
   ```
   npm run dev
   ```

3. **Відкрийте браузер** за адресою, яка відображається в терміналі (зазвичай `http://localhost:5173`)

## Функціонал

### Компоненти:
- **ProductCard**: відображає назву, ціну, рейтинг (зірочки) та кнопку "В кошик"
- **Cart**: сторінка зі списком доданих товарів та підрахунком загальної суми
- **Promotions**: блок з акційними пропозиціями
- **Profile**: сторінка користувача з аватаром та статусом

### Маршрутизація:
- `/` - Головна сторінка (Продукти)
- `/cart` - Кошик
- `/promotions` - Акції
- `/profile` - Профіль

### Сортування товарів:
- За ціною (від дешевих до дорогих)
- За ціною (від дорогих до дешевих)
- За рейтингом (від вищого)
- За рейтингом (від нижчого)

## Дизайн

Використано стилістику SportClub:
- Основний колір: `#2563eb` (синій)
- Темний текст: `#1e293b`
- Білий фон: `#ffffff`
- Закріплений header з ефектом розмиття
- Картки товарів з тінією та анімацією при наведенні
- Кнопки з градієнтом `linear-gradient(135deg, #2563eb, #4f46e5)`

## Технології

- **React 18** - UI бібліотека
- **React Router DOM 6** - маршрутизація
- **Vite** - збірка проекту
- **CSS Modules** - стилізація компонентів
